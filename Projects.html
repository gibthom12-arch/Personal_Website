DinoRaider

Type:

  • A Level NEA project
  • Further development done extracurricularly

Accessible Using:

  • Unity

Programming Languages:

  • C#

Key Features:

  • Procedurally generated map
  • Unique creature AI behaviour
  • Unique creature abilities

Key Issues:

  • Uses low quality models some lacking appropriate animations
  • Procedurally generating map causes significant initial loading time
  • Creature hit boxes can be faulty
  • Tamed creatures can change back to a wild state despite being tamed
  • Lacking a map border allowing creatures/players to wander out of bounds

Description:

A player is placed into a world surrounded by a variety of creatures. The player is free to roam and interact with these creatures. By collecting and using 3 taming potions they are able to turn a creature their own side and fight alongside it. These taming potions can be found spawning randomly across the map.

CLI Store Management Software

Type:

  • University Project - Module: Object Oriented Programming

Accessible Using:

  • Eclipse

Programming Languages:

  • Java

Key Features:

  • Allows for lookup of items using ID or Name
  • Varies permissions and access level depending on type of user
  • Uses a simple easy to use numerical CLI
  • Has effectove exception and error handling
  • Has effective input validation
  • Allows for multiple payment types
  • Allows for new items to be entered and purchased

Key Issues:

  • Lacks effective user authentication
  • Lacks ability to see statistics of sales using graphs
  • Unable to remove items from the stock

Description:

This software uses a CLI to manage operations for a store. It customers to search, add to basket and purchase items they desire. It also gives special permissions to admins to view special details about stock and add new items to the stock.

GUI Store Management Software

Type:

  • University Project - Module- Programming and Databases

Accessible Using:

  • Google Colab

Programming Languages:

  • Python

Key Features:

  • Search lookup system
  • Allows renters to provide feedback
  • Allows new games to be entered and be seen for customers to rent
  • Provides charts to view the amounts sold of each game
  • Authenticates user to determine access level to features

Key Issues:

  • Lacks effective validation of inputs
  • Lacks complete error handling
  • Accounts lack passwords making the accounts insecure
  • New accounts cannot be created

Description:

This software was built as an academic project for a hypothetical game store to use. It allows for renting and returning of games, and entering of feedback once a game is returned. It provides the admin with permissions to add new games and view the sales and sales performance of games they have sold.

Wumpus World AI

Type:

  • University Project - Module- Artificial Intelligence

Accessible Using:

  • Google Colab

Programming Languages:

  • Python

Key Features:

  • Relies entirely pre-defined rules to traverse a partially observable map
  • AI is able to use inferences from previous actions to influence later descisions
  • New Sniper obstacle added into the map for AI to avoid and kill
  • Works effectively on a number of map layouts
  • Each descision the AI makes can be clearly explained by parsing through its reasoning

Key Issues:

  • Untested on maps of differing sizes
  • Untested on differnet starting points

Description:

This AI uses a set of pre-defined rules to traverse a map find the gold and return to their initial starting point. The map is partially observable and the AI only knows the safety of tiles it is currently on or those it has already traversed.

Country Information Tracker

Type:

  • Personal Project

Accessible Using:

  • Code viewable via Github

Programming Languages:

  • HTML
  • CSS
  • Javascript

Key Features:

  • Collects information from Countries.dev REST api
  • Has search function to quickly find data about desired country
  • Uses Geo.Json alongside Leaflet.js to form an interactive map for users to find information
  • Includes location markers to show where the searched country is
  • Has loading and error handling to provide consistent feedback to the user

Key Issues:

  • Use cases for this application are limited and not well thought out
  • GUI design could be improved

Description:

Web application for the purpose of searching and exploring country information. It includes a searching function which allows users to quickly find countries they need, also supporting an interactive map to promote exploration.
